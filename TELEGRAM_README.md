# Как отправить сообщение в телеграм?
- Для того чтобы отправлять сообщения в телеграм, нужно использовать данные
из колонки telegram_chat_id таблицы users в БД. Если у вас этой колонки нет,
то нужно запустить проект user_service, чтобы в таблицу добавилась данная колонка.
Добавлять значения нужно будет вручную.

# Как получить chat_id?
- Для этого нужно запустить данный проект, перейти в телеграм по ссылке https://t.me/thestral8_bot
и написать любое сообщение. Затем в логах найти "chat id" и добавить его в колонку telegram_chat_id для таблицы user.
